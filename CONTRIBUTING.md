# Contributing to Tamil Nadu Population Dashboard

Thank you for your interest in contributing to this project! This guide will help you get started.

## How to Contribute

### 1. Reporting Issues
- Use the [GitHub Issues](https://github.com/methila-2056/Tamil-Nadu-Dashboard-By-PowerBI/issues) page
- Describe the issue clearly with steps to reproduce
- Include screenshots if applicable

### 2. Suggesting Enhancements
- Open an issue with the `enhancement` label
- Describe the feature and its use case
- Explain how it improves the dashboard

### 3. Data Contributions
- Ensure data comes from official Census/Government sources
- Follow the existing CSV format in `TN_Districts_Data.csv`
- Include source citations

## Development Guidelines

### Power BI Best Practices
- Maintain consistent color schemes and fonts
- Ensure all visuals are accessible (color-blind friendly palettes)
- Test all interactive filters before submitting
- Document any new DAX measures

### Data Standards
- Use official district names (English and Tamil)
- Maintain consistent number formatting
- Validate data against Census of India records

## Pull Request Process

1. **Fork** the repository
2. **Create** a feature branch (`git checkout -b feature/amazing-feature`)
3. **Commit** your changes (`git commit -m 'Add amazing feature'`)
4. **Push** to the branch (`git push origin feature/amazing-feature`)
5. **Open** a Pull Request

### PR Checklist
- [ ] Dashboard renders correctly
- [ ] All filters function properly
- [ ] Data is accurate and sourced
- [ ] README is updated if needed
- [ ] No breaking changes to existing visuals

## Code of Conduct

- Be respectful and inclusive
- Focus on constructive feedback
- Help newcomers learn

## Questions?

Feel free to open an issue for any questions about contributing!
